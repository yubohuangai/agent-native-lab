# agent-native-lab

A blog-style proposal for making the Vision &amp; Learning Lab's management
workflow **agent-native** — handing tedious lab chores (inventory, papers/journal
club, meetings, website, servers) to AI agents you talk to in plain English.

**Live page:** https://yubohuangai.github.io/agent-native-lab/

The proposal is a single self-contained `index.html` (inline CSS, prose only),
served via GitHub Pages. It argues the vision and uses **Atlas**, the lab's
already-running inventory agent, as the written proof.

Related: [lab-inventory-bot](https://github.com/yubohuangai/lab-inventory-bot) — Atlas's source.
